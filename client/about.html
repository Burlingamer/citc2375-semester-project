About

This is the InfraClicker about page. It is my CITC 2375 Semester Project. It is a clicker game that will eventually have many upgrade options, progression mechanics, and a store. The "problem" it will address is boredom, and the fact that most clicker games are very linear and don't have much challenge. This game will have some challenge as it progresses and hopefully will be fun to play. I'd like it to be a game anybody could play, but obviously more fun for those who more actively play it. Overall, for the reasons of this project, it is a game that focuses on a collection of generators, upgrades, and other progression items.
