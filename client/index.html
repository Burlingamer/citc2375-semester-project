This is the InfraClicker main page.
It will contain the core functions of the application.
For now, it has simple examples of what may be included in the future.

Manual Clicker

Manual unit generator

Level: 0

Units per cycle: 1

Cycle time: 1 second

All-time yield: 0

This will be the very beginning element of the game, a manual clicker button.
It will generate a fair amount of units per click and will remain relevant in later stages of the game.
It will be upgradable to increase its yield and speed.

AutoClicker

Standard automated unit generator

Level: 0

Units per cycle: 1

Cycle time: 5 seconds

All-time yield: 0

This will be the first upgrade the player can purchase.
As the name implies, it will automatically generate units for the player.
It will be upgradable to increase its yield and speed.

Overclock

Time-based consumable

Level: 0

Effect: 2x yield across all Infrastructure

Lifetime: 10 seconds

All-time yield: 0

This will be a temporary status effect that can be activated by the player.
It will increase yield across player Infrastructure for a limited duration.
However, it will also have a cooldown period and also a specific window it
can be activated. Otherwise, it will be wasted.
